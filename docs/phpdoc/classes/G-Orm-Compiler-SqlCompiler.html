SqlCompiler.php : 19

Default, engine-neutral SQL compiler.

Stateless and reusable. It parameterises every value with positional ? placeholders and emits a flat binding list in placeholder order. It never quotes identifiers: identifiers are emitted exactly as provided, which keeps expressions, aliases and qualified names ("t.col", "COUNT(*) AS n") transparent and avoids breaking valid SQL. Identifier quoting, when needed, is the connection's concern.
