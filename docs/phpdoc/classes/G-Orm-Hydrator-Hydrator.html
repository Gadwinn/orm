Reflection-based hydrator bridging the column world and the entity world.

It maps strictly through the entity metadata. Entities are built without invoking their constructor so partial rows never require constructor arguments. Native enums are converted to and from their backing value.

PHP 8.3 safety: extraction never reads an uninitialized typed property (it is skipped, i.e. treated as "unknown"), and hydration only writes the properties actually present in the row, so partial selections never touch absent fields. The primary key is always part of the loaded set.

Rich types cross the boundary through ValueConverterInterface converters, resolved by the property's declared (or inferred) type. Conversion happens at extraction as well as at hydration, so snapshots, change diffs and statement bindings all operate on the scalar database form: an equal-but-distinct object instance is never a phantom change, and no reference type is shared between an entity and its snapshot. DateTimeImmutable ships as the built-in converter; additional ones can be registered through the constructor, keyed by type name.
