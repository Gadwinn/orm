QueryState.php : 24

Structural carrier of an accumulated query.

This is the decoupling boundary between the Query Builder and the SQL compiler: the builder fills a QueryState while the developer chains calls, and the compiler reads it to produce SQL and bindings. It holds no behaviour and performs no escaping; identifiers are stored exactly as the developer provided them (SQL-first, no hidden rewriting), and values are kept raw so the compiler can parameterise them.

A "predicate" entry (used by both WHERE and HAVING) has the shape: array{boolean: 'AND'|'OR', column: string, operator: string, values: list, raw: bool} where values holds 0 (IS [NOT] NULL), 1 (most operators), 2 (BETWEEN) or more (IN / NOT IN) raw values. When raw is true the entry is a verbatim HAVING expression (column holds the whole fragment, operator is empty) and the compiler emits it as-is with values as its bindings.
