QueryExpressionClause.php : 19

Concrete expressive clause produced by QueryBuilder::where()/having() when called with a column only.

It carries the pending column together with the boolean connector and the target clause (WHERE or HAVING) chosen by the originating call. Each operator finalises the predicate on the owning builder and returns that builder so the fluent chain continues.
