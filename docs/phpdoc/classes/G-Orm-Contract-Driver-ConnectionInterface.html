ConnectionInterface.php : 17

Wraps an open database session.

Exposes explicit transaction control, value/identifier quoting, statement preparation and the SQL platform (dialect) of the engine behind the session. Transaction control is deliberately explicit: the connection never opens or commits transactions on its own.

The identifier generated by the last INSERT on this session.

public lastInsertId([string|null $name = null ]) : string|int

The last inserted id is state owned by the database session, not by an individual statement result. For tables with a composite primary key (no single auto-generated column) this returns 0, or throws, depending on the engine — standard behaviour; callers must rely on extracted key values instead.
