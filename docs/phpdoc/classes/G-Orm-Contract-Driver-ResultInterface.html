ResultInterface
in
  • Application

ResultInterface.php : 14

Wraps the outcome of an executed statement.

For SELECT-like statements it exposes the result set; for write statements it exposes the affected-row count. The last generated identifier is session state and lives on ConnectionInterface, not here.
