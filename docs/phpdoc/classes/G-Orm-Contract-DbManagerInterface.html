DbManagerInterface.php : 22

Primary entry point of the ORM.

The DbManager exposes the four usage levels of the package:

  1. Raw SQL -> query(string $sql, array $bindings)
  2. Query Builder -> query()
  3. Repositories -> repository(EntityClass::class)
  4. Unit Of Work writes -> persist() / remove() / flush()

The implementation is responsible for wiring the active connection, the Unit Of Work and the metadata layer together. Construction is a concrete concern (e.g. DbManager::create(...)) and is intentionally kept out of this contract.

Synchronise all pending changes with the database.

public flush() : void

Inserts, updates (modified columns only) and deletes computed by the Unit Of Work are executed. This does NOT commit an SQL transaction.

Lifecycle rule: flush() may be called several times inside a single transaction block before commit() or rollBack() is invoked. When no transaction is active, a flush() applies its changes to the database immediately.
