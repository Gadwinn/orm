MetadataReader.php : 33

Reads PHP 8.3 mapping attributes through native reflection and builds the structured metadata consumed by the rest of the ORM.

Results are memoised per class for the lifetime of the instance so a class is reflected only once. A PSR-16 layer can be added later as a decorating reader without changing this contract; the produced metadata objects hold only plain data and are safe to cache.
