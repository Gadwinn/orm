OrmFactory

Composition root for one or several databases.

The factory holds named connection configurations and lazily builds one fully wired DbManager per name, cached for the factory's lifetime. Each named manager owns its private Unit Of Work and Identity Map, so two databases in the same project never share tracking state; transactions are per connection.

Three configuration shapes are accepted, normalised to the option array the PDO driver consumes:

  • PDO DSN string: 'pgsql:host=127.0.0.1;dbname=shop' (a bare DSN cannot carry credentials — use the array or URI form when a user/password is needed)
  • option array: ['driver' => 'mysql', 'host' => ..., 'user' => ...] (the exact contract of PdoDriver::connect())
  • URI string: 'mysql://db_user:db_password@127.0.0.1:3306/db_name' (scheme aliases like mariadb/postgres/mssql resolve to their PDO driver; percent-encoded credentials are decoded; recognised query parameters are kept, unknown ones — e.g. serverVersion — are ignored)

Security: a URI may embed credentials, so when one cannot be parsed the exception deliberately never echoes the configuration string.
