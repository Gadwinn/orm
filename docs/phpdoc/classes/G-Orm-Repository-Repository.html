Repository.php : 33

Generic, entity-typed repository.

Lookups by primary key consult the identity map before issuing SQL so a row is represented by a single instance for the lifetime of the Unit Of Work. Every hydrated row is registered with the Unit Of Work, which seeds the identity map and captures the original-state snapshot. Persistence is delegated wholesale to the Unit Of Work; the repository never emits write SQL on its own.

Custom repositories extend this class so they inherit the constructor and can be auto-wired by the DbManager.

public save(object $entity) : void

This is a thin wrapper that delegates to the underlying Unit Of Work: the entity is scheduled and the pending changes are flushed. No SQL is issued directly by the repository, so all snapshots, transactions and state tracking stay on the single unified persistence pipeline. Inside an active transaction this applies the write without committing it.
